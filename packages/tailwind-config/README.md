# @etnos/tailwind-config

Configuração compartilhada de estilos Tailwind e PostCSS para o monorepo.

## Arquivos exportados

- `shared-styles.css`: base de estilos comum;
- `postcss.config.js`: config PostCSS reutilizável (`@etnos/tailwind-config/postcss`).

## Integração no monorepo

Usado nos apps Next.js (`web`, `admin`, `student`), Storybook (`apps/docs`) e
demais bibliotecas com Tailwind.
